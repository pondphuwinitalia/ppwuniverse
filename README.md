# Our Blue Universe — PondPhuwin 🩵

Una fanpage statica, responsive, in bianco e azzurro pastello, con animazioni, galleria personalizzabile e lettera interattiva.

## Anteprima in locale
Apri `index.html` nel browser. Per un'esperienza migliore puoi usare l'estensione Live Server di VS Code.

## Pubblicare su GitHub Pages
1. Crea un repository su GitHub, per esempio `pondphuwin-universe`.
2. Carica `index.html`, `style.css`, `script.js` e `README.md` nella cartella principale del repository.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona `main` e `/ (root)`, poi premi **Save**.
6. Dopo qualche minuto, GitHub mostrerà l'indirizzo pubblico del sito nella sezione Pages.

## Personalizzazioni
- **Foto:** clicca su una delle tre Polaroid e scegli un'immagine dal dispositivo. Questa anteprima è temporanea: per conservarla online, modifica il sito e inserisci l'immagine nei file del repository.
- **Testi:** modifica i testi in `index.html`.
- **Colori e animazioni:** modifica le variabili all'inizio di `style.css`.
- **Timeline:** duplica o modifica i blocchi `.timeline-item` in `index.html`.

## Nota
Progetto fanmade non ufficiale, non affiliato a Pond, Phuwin o GMMTV. Usa solo immagini che hai il diritto di pubblicare e rispetta le condizioni delle piattaforme da cui provengono.
